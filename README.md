# 8-bit ALU Design

An 8-bit Arithmetic Logic Unit implemented in SystemVerilog.

## Features

- Arithmetic: ADD, SUB
- Logical: AND, OR, XOR, NOT
- Shift: SHL, SHR
- Registered output interface
- Carry, zero, and overflow flags

## Project Structure

- `SPEC.md`: Functional specification
- `architecture.md`: Datapath architecture
- `test_plan.md`: Verification plan
- `rtl/`: RTL source files
- `tb/`: Testbench source files
- `reports/`: Simulation and synthesis reports
